# Fantasy Chess

Play at **https://perseus-sepahi.github.io/fantasy-chess/** — on a computer, tablet or phone.

Two themes: **Stone Hall** (living stone chessmen with ancient weapons that break apart under
real physics) and **Sketchbook** (hand-drawn doodles on paper). Play the computer at four levels,
a friend on the same device, or watch the computer duel itself.

This repository holds the published website only.
